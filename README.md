# 🧮 Simple Calculator

A clean and functional **Calculator Web Application** built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations with a simple and user-friendly interface.

## ✨ Features

* Perform addition, subtraction, multiplication, and division
* Clear display functionality
* Error handling for invalid expressions
* Lightweight and beginner-friendly design

## 💻 Technologies Used

* HTML – Structure of the calculator interface 
* CSS – Basic styling and layout 
* JavaScript – Calculator logic and operations 

## 🚀 How to Run

1. Clone or download the repository
2. Open `index.html` in your browser
3. Start calculating

## 📌 Purpose

This project is ideal for beginners to practice JavaScript functions, DOM manipulation, and basic arithmetic logic in web development.
