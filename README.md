# 🧮 Orbit Calculator

A simple and user-friendly calculator web application built using **HTML, CSS, and JavaScript**. The project provides a clean interface for performing basic mathematical calculations directly in the browser.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear/reset functionality
- ⌫ Delete/backspace functionality
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and responsive design
- **JavaScript** – Calculator logic and user interactions
