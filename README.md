# Orbit Calculator

A responsive, dependency-free calculator built with HTML, CSS, and JavaScript.

## Features

- Responsive layout for phones, tablets, and desktops
- Standard arithmetic with correct operator precedence
- Decimal, percentage, sign-toggle, clear, and backspace controls
- Keyboard support
- Accessible labels, visible focus states, and reduced-motion support
- Safe custom expression parser; no use of `eval`

## Run locally

Open [file.html](file.html) in any modern web browser. No installation or build step is needed.

## Keyboard controls

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a number |
| `+`, `-`, `*`, `/` | Choose an operator |
| `.` | Add a decimal point |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last entry |
| `%` | Convert the current number to a percentage |
| `C` or `Esc` | Clear the calculator |

## Project files

- `file.html` — page structure and calculator controls
- `style.css` — responsive visual design
- `script.js` — calculator state, keyboard input, and expression parsing
